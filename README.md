# QuePlugins

QueMusic 的官方插件仓库：歌词界面插件、功能插件、音乐平台插件。

## 目录结构

```
lyrics/<插件id>/        歌词界面插件
  info.json             插件信息（必要）
  <entry>.qml           入口 QML（必要）
  info.png              预览图（建议，列表里显示）
  shaders/*.frag        自定义着色器（可选）
docs/                   开发规范
Tools/                  功能插件（规划中）
Network/                音乐平台插件（规划中）
```

## 安装歌词界面插件

1. 下载本仓库（或某个插件文件夹）
2. QueMusic → 设置 → 插件 → 歌词界面 → **安装插件**，选择插件文件夹
3. 点该插件的 **启用**
4. 播放页左上角**第二个按钮**可以随时切换歌词界面

插件目录会显示在设置页上，也可以点 **打开插件目录** 手动放置。

## 提交插件

1. Fork 本仓库，新建 `lyrics/<你的插件id>/`
2. 按 [规范](docs/lyrics-plugin.md) 补齐 `info.json`、入口 QML，建议附 `info.png` 预览图
3. 发 PR，描述里附一张运行截图

> 插件是 QML 代码，会以应用权限运行，请只安装你信任的插件。核心作者审核时会人工查看代码。

## 许可

插件代码默认与本仓库一致（Apache-2.0），插件内可另行声明。
