# 恶搞广告（整活向）

往四个扩展点塞满「1刀999」传奇广告：

| 位置 | 内容 |
| --- | --- |
| `titlebar` | 呼吸闪烁的 VIP 徽章，点它会把「今日推荐」再叫出来一次 |
| `player` | 底栏「手气不错 · 点击就送」 |
| `sidebar.bottom` | 传奇卡片：广告图 + 立体大字 + 斜贴的「限时」+ 「立即试玩」 |
| `window.overlay` | 跑马灯横幅 + 右下角「今日推荐」弹窗（关闭按钮故意又小又偏，「残忍离开」头 1.5 秒点不动） |

文字、光效、按钮全是本地绘制，点哪儿都不会跳转、不联网。

## 换成你自己的广告图

弹窗和侧栏卡片都读 `assets/ad.jpg`，直接替换即可：

```
assets/ad.jpg       当前使用的广告图（720×720 左右，JPG，控制体积）
assets/ad-alt.jpg   另一张备选，想换把文件名对调就行
```

图缺失或读不动时会自动退回纯自绘的红底广告样式，不会显示空白。

> **授权提醒**：本插件自带的图是可自由使用的自绘/生成素材。网上流传的页游广告图（含角色、
> 明星、商标）大多是商业素材，自己本地玩玩没问题，但**不要提交进公开仓库**。
> 想找可自由使用的素材，可以去 OpenGameArt（CC0）、Pixabay 这类站点。
